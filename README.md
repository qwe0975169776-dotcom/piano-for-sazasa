# 雙手鍵盤教室

國小音樂課用的雙手鍵盤練習網頁。學生右手彈旋律（Do4–Si4），左手按和弦，搭配電子琴自動伴奏一起合奏。

- **學生版**：`https://qwe0975169776-dotcom.github.io/piano-for-sazasa/`
- **老師版**：`https://qwe0975169776-dotcom.github.io/piano-for-sazasa/teacher.html`

（倉庫：https://github.com/qwe0975169776-dotcom/piano-for-sazasa）

---

## 一、第一次上架到 GitHub

1. 登入 GitHub，點右上角 **＋** → **New repository**。
2. **Repository name** 填 `piano-for-sazasa`，選 **Public**，按 **Create repository**。
3. 在新倉庫頁面點 **uploading an existing file**（或 **Add file → Upload files**）。
4. 把資料夾裡的 **7 個檔案全部一起拖進去**：
   `index.html`、`teacher.html`、`songs.js`、`app.js`、`style.css`、`README.md`、`CHANGELOG.md`
5. 拉到最下面按 **Commit changes**。
6. 點上方 **Settings** → 左邊 **Pages**。
7. **Branch** 選 `main`，旁邊資料夾選 `/ (root)`，按 **Save**。
8. 等 1～3 分鐘，打開上面的學生版網址確認。

> 如果你原本已經有放這個網頁的倉庫，直接做第 3～5 步就好，新的 `index.html` 會取代舊的。

## 二、日常使用

### 修改樂譜，讓學生看到新版
1. 開 **老師版** → 選曲子 → 按 **🔒 樂譜修改器**，輸入密碼後修改。
2. 按 **套用變更**。這時只有你這台電腦看得到（「發布與備份」會出現紫色提醒）。
3. 確認沒問題後，按 **📦 下載曲譜檔 songs.js**。
4. 到 GitHub 倉庫 → **Add file → Upload files** → 把剛下載的 `songs.js` 拖進去 → **Commit changes**。
5. 等 1～3 分鐘，學生重新整理網頁就會看到新樂譜。

> 下載的檔名如果變成 `songs (1).js`，上傳前請先改回 `songs.js`，不然不會取代舊檔。

### 記錄學生進度
- 在老師版的「樂譜」區選學生，聽完一小節沒問題就點小節右下角的圓圈打勾。
- 要整理成表格：按 **📊 匯出進度表 CSV**，用 Excel 或 Google 試算表開啟（可以貼進你的學生紀錄表）。

### 備份與換電腦
- 進度和還沒發布的樂譜修改 **只存在這台電腦的瀏覽器裡**，清除瀏覽紀錄或換電腦就看不到。
- 建議每週按一次 **💾 備份進度與草稿**，把檔案存在雲端硬碟。
- 換電腦時，開老師版 → **📂 還原備份** → 選備份檔。

## 三、注意事項

- **老師版不是秘密頁面**：GitHub Pages 的網頁是公開的，知道網址的人都能打開，修改器的密碼也寫在程式裡。它只能防止學生不小心改到。學生版不會放老師版的連結。
- **不要把備份檔或 CSV 上傳到 GitHub**，裡面有學生名字。
- 學生看到的永遠是 GitHub 上的 `songs.js`，老師在自己電腦上改了沒發布，學生不會受影響。
- 學生在平板或手機上沒聲音時：先點一下播放按鈕，再確認裝置不是靜音模式。
- 更新後學生還看到舊版：請他們重新整理網頁（電腦按 `Ctrl + F5`）。

## 四、曲譜格式（進階）

`songs.js` 裡每一小節長這樣：

```js
{ r: "E4 1 E4 0.5 F4 0.5 G4 1 E4 1", l: "C", a: "q" }
```

- `r` 右手：「音高 拍值」成對；休止符 `R 1`；指定指法 `G4/4`；每小節共 4 拍；音域 C4–B4 白鍵。
- `l` 左手和弦：`C`、`F`、`G`、`A`（A 代表 Am）；一小節兩個和弦寫 `F|G`。
- `a` 左手樣式：不寫＝單音、`q`＝四分琶音、`e`＝八分琶音、`c`＝疊和弦。

格式寫錯時，網頁最上面會出現紅色的「曲譜檢查」提示，告訴你哪一首第幾小節有問題。
